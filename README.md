# Nuque Droite

Application pour garder la tête droite au bureau et ne pas se faire mal à la nuque : suivi de posture par la caméra, réglage de la hauteur d'écran, exercices guidés, Pomodoro. Les images restent sur l'ordinateur.

- **Version web** : https://fcasado69.github.io/nuque/ (branche `gh-pages`)
- **App de bureau Mac + Windows** : dossier `desktop/`, fabriquée automatiquement par GitHub Actions. Téléchargements : page *Releases*.
  - Windows : `Nuque-Droite-Installation.exe` (sans droits administrateur) ou `Nuque-Droite-Portable.exe`
  - Mac : `Nuque-Droite-Mac.dmg`

L'app de bureau charge la version web en ligne (toujours à jour) et ajoute : icône près de l'horloge / dans la barre des menus, fonctionnement en fond, pastille toujours au premier plan, flou de l'écran quand la mauvaise posture dure, lancement au démarrage.
