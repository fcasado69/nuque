# nuque
Application pour garder la tête droite au bureau et ne pas te faire mal à la nuque.

**Nuque Droite** analyse la posture avec la caméra (tout reste sur l'ordinateur, rien n'est envoyé) :
réglage guidé de la hauteur d'écran, suivi en direct de 14 points de posture, alertes, pauses et historique.

Ouvrir la page dans Chrome, puis « Installer Nuque Droite » (icône dans la barre d'adresse) pour l'avoir dans le Dock.
